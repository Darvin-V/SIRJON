Mission Objective

Verify physical equipment readiness, execute emergency conveyor motor electrical cutoff, and suppress simulated Class B solvent fire using the physical extinguisher PASS method.

info

Operational Drill Scope

This practical drill trains operators to react within the critical 30-second window of initial solvent vapor combustion. Combines physical equipment identification with AR-projected flame dynamics, thermal radiant zone calculation, and physical tool handling.
